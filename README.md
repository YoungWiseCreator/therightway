# therightway

**Etz Chaim — The Right Way** · therightway.life

The Bible site for The Right Way channel (@TheRightWay): the whole Bible, chapter by
chapter, in order — 66 books, 1,189 chapters, one episode each, depicted as written
from the oldest proven KJV and the Hebrew Bible, cross-checked against the Dead Sea
Scrolls where proven texts exist.

Static GitHub Pages site (plain HTML/CSS/JS, no build step). Generated by
`build_site.py` (kept with the build records outside this repo).

**Donations:** every Donate button reads the single `DONATE_LINK` constant at the
top of `assets/config.js`. LIVE since 2026-11-18: a Stripe donation link
(donor-set amount, submit_type=donate) on the fleet account of record
(AIDCOS, acct_1TbMSGFRf1U6fUlZ) — payment link
plink_1UdE2jFRf1U6fUlZglemG2FQ. `assets/site.js` points every anchor that
links to `donate.html` and is labelled Donate at that constant.
